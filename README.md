The Application is developed in React Js using vite. Prerequisite: Node.js.

### Steps For Project Setup and Running Project:
#### 1. Clone the project using Git

#### 2. Install packages
> npm install

#### 3. Create .env file in root directory and paste following line:
> VITE_API_URL=https://localhost:7241

#### 4. Run application using following command:
> npm run dev
